# 06 · 面试包：豆柴 · 私域 AI 业务运营

> 反向面试 + 谈薪剧本 + 入职 90 天。**只在你受邀后才做**，不投递阶段做。
> 候选人为虚构「林舟」，数据为演示数据。

---

## 一、反向面试（我问对方，不是对方问我）

### 1.1 问 HR（第一轮）

| 问 | 想确认什么 | 红线答案（听到就走） |
|---|---|---|
| 这个岗为什么现在开？前任去哪了？ | 岗位真实性 | "前任被优化/团队刚裁过" |
| 私域团队现在几人？汇报给谁？ | 组织位置 | "你一个人干"（无团队） |
| 15–25K 是几薪？试用期打折吗？ | 薪资结构 | 试用期 8 折 + 无年终 |
| 公司现在最急的三件事是什么？ | 真实优先级 | "都在急"（没重点） |

### 1.2 问业务负责人（第二轮）

| 问 | 想确认什么 |
|---|---|
| 私域现在的复购率/客诉率，口径是怎么定的？ | 数据成熟度 |
| 2026 扩品类/扩商超，私域的角色是什么？ | 岗位真命题 |
| AI 工具现在用到什么程度？预算多少？ | 资源真实性 |
| 服务团队和私域怎么分工？AI 会替代谁？ | 组织风险 |
| 如果我 90 天只做成一件事，你希望是什么？ | 优先级 |

### 1.3 问未来同事（终面/加面）

| 问 | 想确认什么 |
|---|---|
| 你在这最难受的一件事是什么？ | 真实痛点 |
| 上一个做这个岗的人，做得好的地方是什么？ | 隐性期望 |
| 老板做决定快吗？会改主意吗？ | 管理风格 |

### 1.4 红线（任何一条出现，慎重）

- 岗位是"一个人干完所有事"。
- 公司要求"先做 GMV，别管服务"。
- 老板频繁改方向、无决策机制。
- 薪资结构有隐藏扣款。

## 二、谈薪剧本

### 2.1 先算 BATNA（我的备选）

| 项 | 内容 |
|---|---|
| 我的 BATNA | 手上还有 2 家 A 类在谈 + 可接受 6 个月空窗 |
| 底线 | 20K（低于不考虑） |
| 目标 | 23K |
| 理想 | 25K |

### 2.2 锚定 + 确认价值 + 报价

**顺序**：先让对方确认价值 → 再报锚 → 再让步。

```
（对方问期望薪资）
"我想先确认一下：这个岗位 90 天最想解决的是'扩品类接新品'还是'服务提效'？
（对方答后）
如果是前者，我的方案里第 1 件就是接新品；如果是后者，第 2 件是服务 SOP。
这两件我都在上一份工作里做成过（会员 0→1、客诉 48h→6h）。
所以我期望 23–25K，具体可以按 90 天结果谈。"
```

> 关键：**先让对方说"这个岗要解决什么"，再把自己的价值挂上去，最后才报价。**

### 2.3 僵局 5 选项（对方压价时）

| 选项 | 话术 | 适用 |
|---|---|---|
| 1. 保底薪、让绩效 | "底薪 21K，绩效按复购率达成给，可以吗？" | 对方预算紧但认可你 |
| 2. 保总包、让结构 | "总包 25K 不变，底薪/绩效比例可以调。" | 对方在意现金流 |
| 3. 保级别、让时间 | "先按 21K 入职，3 个月转正后按结果调。" | 你想先进去 |
| 4. 保成长、让薪资 | "薪资我让 1K，但我要带团队/主导 AI 项目。" | 你更看重成长 |
| 5. 不接 | "谢谢，这个数和我预期差距较大，先不勉强。" | 低于底线 |

### 2.4 谈薪禁忌

- ❌ 先说"都可以"（失去锚点）。
- ❌ 拿"另一家给多少"压对方（除非真有）。
- ❌ 只谈钱不谈价值（对方只会压价）。
- ❌ 接受"画饼"（期权/未来调薪）当现金。

## 三、入职 90 天（活下来，不是证明自己）

### 3.1 三段

| 阶段 | 目标 | 动作 |
|---|---|---|
| 0–30 天 | **活下来 + 摸清** | 不急着改，先摸口径/流程/人；输出"现状地图" |
| 31–60 天 | **做出一个小结果** | 选 1 个高频痛点（如客诉响应），做 1 个自动化试点，跑出对照数据 |
| 61–90 天 | **拿到信任** | 把试点结果汇报给管理层，争取下一阶段资源 |

### 3.2 四个坑

| 坑 | 说明 | 避法 |
|---|---|---|
| 一上来就改革 | 老员工抵触 | 先问"你们现在怎么做的"，再提改进 |
| 只做执行不建机制 | 变成"高级打杂" | 每个动作都沉淀成 SOP/表 |
| 和一线抢功 | 团队不服 | 把功劳给一线，自己拿"机制" |
| 只对上不对下 | 信息断层 | 每周和一线聊 1 次 |

### 3.3 90 天汇报模板

```
做了什么：___
数据变化：___（对照基线）
沉淀了什么：___（SOP/表/机制）
下一步建议：___
需要什么支持：___
```

## 四、面试后 24 小时动作

- 发一封感谢邮件（3 句话：感谢 + 补一个面试没讲透的点 + 重申兴趣）。
- 把面试里听到的"真命题"回填到 `07_复盘与校准`。
- 48 小时没回复 → 跟进一次；一周没回复 → 归档。
