# 豆柴 · 真实公司案例（v4 全流程 00–07）

## 这个案例和「山海咖啡」有什么不同

| | 山海咖啡 | 豆柴（本案例） |
|---|---|---|
| 公司 | 纯虚构 | **真实公司**（豆柴，宠物食品，2014 年成立） |
| 数据 | 编的（演示结构） | **真实、可核验、带来源和年份** |
| 候选人 | 纯虚构 | **虚构候选人**（代号「林舟」，非真人） |
| 用途 | 演示五层结构怎么填 | 演示**一家真实公司 + 一个虚拟高匹配候选人**的完整八件套 |

> **脱敏说明**：公司名和公司研究是真实的（公开信息），候选人信息全部虚构，不涉及任何真人。
> 这样做是为了让你看到"真实公司 + 真实数据"下，五层蒸馏和八件套长什么样。

## 读这个案例的顺序

1. 先读 `00_用户诊断.md`，看"先诊断人"长什么样；
2. 再读 `01_公司蒸馏.md`，看五层和退稿规则怎么落地；
3. 然后 `02 → 03 → 04 → 05`，看怎么从研究走到投递；
4. 最后 `06 → 07`，看面试和校准怎么闭环。

## 注意

- 豆柴的数据截至 2026-11，来自公开信息（见 `04_证据附录.md` 的来源表）。
- 本案例中的候选人「林舟」是虚构的，但他的能力结构（会员 0→1、企微提效、服务质检）是真实岗位常见的能力组合，可作参考。
- 如果你要套用这个案例，**只换候选人，不换公司结构**——公司研究可以复用，匹配和方案必须按你自己的情况重做。
