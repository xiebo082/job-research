# 投递方案模板（≤1 页 A4，对外版）

> 只写能验证的内容；写不出来的，删掉。
>
> **这是给 HR / 用人经理看的文件**：只说"我看到什么、我打算怎么做、我的假设是什么"。
> **不写**：公司战略哪里错了、竞品哪里不行、内部组织问题、薪资谈判、面试问题——这些放 02 岗位蒸馏或 04 证据附录（内部）。

> **排版契约（`references/13_排版规范.md`）**：全文 **≤80 行**（一页 A4）；结论性数字加粗；不写内部判断。

## 对外文档三条禁令（v4.8，违反即退稿）

> [!danger] 这三条会让对方觉得"这是 AI 批量生成的"
>
> **禁令一：不写关于文档本身的任何话。**
> 删掉「对外文档（可发 HR / 面试官）」「不含面试问题 / 内部评价 / 薪资谈判」「内部版 / 对外版」这类标签。文档一开口就解释自己是什么，读者第一反应是"这不是写给我的"。
>
> **禁令二：不出现内部排版语言。**
> 不出现 🔴🟡🟢 色标、`> [!important]`、颜色字典图例、「阅读约定」、「（我的假设）」这类内部标注体系。对外文档只用普通段落、小标题、必要的表格——**看起来像人写的，不像模板渲染的**。
>
> **禁令三：方案没被确认前，不写指标。**
> 「90 天 KPI」「怎么证明我做到了」在首轮方案里是负分：事情还没谈拢就定指标，说明你在表演专业，不是在判断事情。首轮只写**认知 + 顶层设计 + 90 天动作 + 我的假设**。指标留到面试或入职后，等基线摸清再谈。

**一句话**：对外方案要像"一个人看完资料后写的判断"，不像"一个系统按模板输出的报告"。

## 标题
公司 · 岗位 · 日期 · 假设版

开场一段（≤80 字）：我看完公开信息，先说几个我看到的事实，再说我判断的问题和打算怎么做。

## 一、我看到的事实（2–3 条，每条一个数字）
1. ___（反直觉的那条放第一）
2. ___
3. ___

> 写法：事实要能被对方当场验证（"40 亿 ÷ 71 元 ÷ 9000 万人 = 0.63 件/人"），不要写"贵司非常重视用户"。

## 二、我判断的真问题（认知，这是全篇最值钱的部分）
先写"大多数公司会怎么做"，再写"为什么在这家/这个品类会失效"，最后给出你的判断。

- 常规做法：___（例如上等级、上积分、上权益）
- 在这里会失效，因为：①___ ②___ ③___
- **所以我认为，___ 不是 ___，而是 ___。**

> 这一节写不出"反常识但能验证"的句子，就说明调研不够，回去补 `05_会员体系调研` 这类专项，别硬写。

## 三、如果是我，会怎么做（顶层设计）
**一个主机制 + 1–2 个支撑**，不要列十条。

- **主机制**：___（一句话说清它怎么解决第二节的问题）
- **支撑一**：___（通常是前置条件：数据、认人、供给）
- **支撑二**：___（通常是规则：权益、定价、激励）

> 判据：主机制必须是"机制"不是"动作"。写"做积分商城"是动作，写"用周期购把复购从随缘变可预测"是机制。

## 四、前 90 天（只写动作，不写指标）
| 阶段 | 做什么 | 产出 |
|---|---|---|
| 0–30 天 | ___ | ___ |
| 31–60 天 | ___ | ___ |
| 61–90 天 | ___ | ___ |

> 每件事都要回答"为什么先做这个"——一句话即可，但必须有。

## 五、我的假设，以及可能错在哪
1. 假设一：___
2. 假设二：___
3. 假设三：___
4. **最可能错的一条**：___（说清如果错了，方案要怎么改）

> 这一节不是自谦，是展示判断力：能说清自己判断的边界，比多写三条策略更可信。

## 六、PDF 版（默认做，可调）
- **默认规则**：S / A / B 级出 PDF；C 级不出。用户可改（"全出" / "全不出"都听用户）。
- 一条命令：`python3 tools/03_to_pdf.py 03_投递方案.md` —— 自动转 HTML → Chrome 打印 → 校验 Pages: 1，超页会逐档缩字号压回 1 页。
- 手动版：A4 单页 HTML + Chrome 无头打印 + `pdfinfo | grep Pages` 验证。
- 对外版：不含文档用途说明、内部色标、指标表、面试问题、竞品贬损、薪资谈判
- 面试问题只放 02_岗位蒸馏

## 附：03 转 PDF 的最小 HTML 脚手架（可选，不阻塞）

> 有 Chrome 就出 PDF，没有就交 Markdown 单文件——**两种都算交付**。
> 用法：把下面存成 `投递方案_A4.html`，把正文粘进 `<main>`，然后：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=投递方案.pdf "file://$PWD/投递方案_A4.html"
pdfinfo 投递方案.pdf | grep Pages   # 必须 Pages: 1
```
