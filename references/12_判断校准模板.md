# 判断校准模板（决策日志回填 · 让下一次判断更准）

> v4 新增。顶尖专家和普通人的差别不在"判断对不对"，在**判断完有没有回填校准**。
> 这份模板解决一个问题：**我怎么知道我的判断是准的，还是只是运气好？**

---

## 一、为什么要校准

求职是一连串判断：
- "这家值得投" → 结果：约面了 / 没约面
- "我能过面试" → 结果：过了 / 挂了
- "薪资能谈到 30K" → 结果：谈到了 / 只给 25K
- "这家公司不错" → 结果：进去 3 个月发现是坑

**不做校准 = 同样的错犯 50 次。**

---

## 二、决策日志（每次投递前写，30 秒）

```markdown
# 决策日志 · <日期> · <公司>-<岗位>

| 项 | 内容 |
|---|---|
| 判断 1：该不该投 | 投 / 不投 / 条件投 |
| 判断 1 的置信度 | 高 / 中 / 低 |
| 判断 2：能约面吗 | 高 / 中 / 低 |
| 判断 3：能过面试吗 | 高 / 中 / 低 |
| 判断 4：薪资能谈到 | X 万 |
| 关键依据 | 最影响我判断的 1–2 条事实 |
| 我可能错在哪 | 一句话 |
```

> 判断 2/3/4 可以只写一个总判断（"我觉得有 60% 概率约面"），但要写数字或高/中/低。

## 三、结果回填（拿到结果后写，2 分钟）

```markdown
# 结果回填 · <日期> · <公司>-<岗位>

| 项 | 原判断 | 实际结果 | 偏差 |
|---|---|---|---|
| 约面 | 中 | 约了 / 没约 | + / - / 0 |
| 面试 | 中 | 过 / 挂 | + / - / 0 |
| 薪资 | 28K | 25K | -3K |
| 公司质量 | 不错 | 有坑 | 负 |

## 偏差原因（选一个，别写"运气"）
- [ ] 信息不足（该查的没查）
- [ ] 判断逻辑错（证据对，推错了）
- [ ] 执行问题（判断对，但打招呼/方案没做好）
- [ ] 外部变化（公司突然不招/换人）
- [ ] 运气（真随机，不归因）

## 下次怎么调
> 一句话：下次遇到类似情况，我改哪个动作？
```

## 四、校准（每 5 次投递做一次，10 分钟）

### 4.1 我的置信度准不准

| 我标"高"的判断 | 实际对了几次 | 结论 |
|---|---|---|
| | / | 高估 / 准确 / 低估 |

| 我标"低"的判断 | 实际对了几次 | 结论 |
|---|---|---|
| | / | 高估 / 准确 / 低估 |

> 常见偏差：
> - **过度自信**：标"高"的经常错 → 下次标"中"，多查一条事实再下判断。
> - **过度谨慎**：标"低"的经常对 → 下次敢冲，别自己先放弃。

### 4.2 我反复在哪个环节错

| 环节 | 错了几次 | 是判断错还是执行错 | 要改的动作 |
|---|---|---|---|
| 选公司 | | | |
| 约面（打招呼/简历） | | | |
| 面试 | | | |
| 谈薪 | | | |

> **只改"执行错"的环节**（动作能改）；"判断错"的环节要先补信息源。

### 4.3 更新我的「判断规则」

把校准结论写成可执行的规则，例如：
- "凡是 JD 写'抗压'且面试只问加班的，我标'低'，不投。"
- "凡是我标'高'的约面，实际约面率只有 30% → 以后标'中'，多投 2 家保底。"
- "薪资谈判我总在'先报价'上吃亏 → 以后一律先让对方说预算。"

## 五、校准的三种粒度（按投入选）

| 粒度 | 什么时候做 | 投入 | 产出 |
|---|---|---|---|
| 单次回填 | 每投一家 | 2 分钟 | 一条偏差记录 |
| 5 次校准 | 每 5 家 | 10 分钟 | 一个偏差模式 |
| 月度复盘 | 每月 | 30 分钟 | 更新的判断规则 |

> 不要求每次都做，但**至少每 5 家做一次**，否则你不知道自己在往哪偏。

---

## 六、和 06_复盘模板 的关系

- `06_复盘模板.md` = 单次投递的**过程复盘**（做了什么、结果如何、哪里可以更好）。
- 本模板 = 跨多次投递的**判断校准**（我的判断准不准、我反复错在哪）。

两份一起用：先做单次复盘，再把结论喂进校准表。
