# 证据附录模板

> **排版契约**：本文件是内部审计材料，不放结论块；但每条来源必须带"链接 + 访问时间 + 置信度"，缺口表用三级降级（试过哪 → 卡在哪 → 用什么替代 → 影响哪条结论）。

## 〇、可信度五档（每条来源必标一档）

> 来源：吸收自 `fact-check`。替代原来的 ✅/⏳/❌ 三态——三态只能表达「打不打得开」，五档才能表达「收窄」「争议」这两种真实状态。

| 档 | 含义 | 能不能进结论 |
|---|---|---|
| 1 已证实 | 有官方或一手原文，可直接引 | 能 |
| 2 基本成立，需收窄 | 方向对，但口径 / 时间 / 范围要限定 | 能，必须带限定语 |
| 3 存在争议 | 多方说法冲突（两套口径） | 只能进「风险」，或单列「口径冲突」 |
| 4 证据不足 | 只有二手转述、匿名单条 | 只能进风险，标「未验证」 |
| 5 明显错误 | 已被反证 | 删掉，并在口径冲突记录里留一行 |

**三条纪律**

1. 每条来源同时标它是 **事实 / 从事实推出的结论 / 价值判断**——三者不许混。
2. 结论要能被事实推出：检查有没有藏假设、有没有把相关当因果、有没有漏掉别的解释。
3. 一个数字一个口径。两套口径并存时，**两个都写，不取平均、不择优**。
