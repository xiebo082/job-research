# 投递动作包模板（S/A/B 必做）

> 边界：只解决「这家公司值不值得聊 → 怎么开口 → 怎么发方案 → 怎么约面试」。**不含面试 Q&A 预演、不含入职方案**——受邀后激活「面试包」，offer 后激活「入职推演」。

> [!important] 这份文件最大的失败模式
> 把人分成 S/A/B/C，然后没有一句能直接发出去的话。
> **分级是我的判断，不是用户的判断。** 用户要的是「今天能不能发出第一句」。
> 所以这份动作包的第一交付物永远是：**一段纯文本、复制粘贴就能发送的首条话术。**

## 交付清单（缺一项就算没做完）

| # | 交付物 | 硬要求 |
|:--:|---|---|
| 1 | 一号位／发声高管画像 | 有原话；查不到就写「无据可查」+ 搜了几轮 |
| 2 | 场景判定 | 这个岗是谁先开口的（对方先找你 / 你主动投递） |
| 3 | **首条话术** | 纯文本、可直接复制、3 点每点一句、结尾发简历 + 一个具体问题 |
| 4 | 待问清单 | 3 个只有内部能答的问题 |
| 5 | 多轮分支 | 对方追问时的回法 |

## 零、一号位画像（动笔前的第一步）

**两个用途**：①判断这家公司值不值得去；②话术和面试里能引用一句真人原话，比任何数字都贴。

**取数顺序（一层查不到就下一层）**：

| 层 | 找谁 | 去哪找 | 记什么 |
|:--:|---|---|---|
| 1 | 创始人 / 实控人 | 36氪、晚点、亿邦、界面、公众号、视频号、B 站 | 公开讲话次数、最锋利的一句原话、履历里的关键决策 |
| 2 | **直接对外发声的高管** | 同上 + 行业峰会、发布会、财报会报道 | CEO / 总裁 / 事业部负责人被媒体引用的原话 |
| 3 | 招聘主体法人 | 天眼查、启信宝 | 实控人是否等于法人（不等于本身就是一条判断） |
| 4 | 都搜不到 | — | 写「无据可查：N 轮搜索，0 篇专访 / 0 场演讲」——**这本身就是一个判断依据** |

**画像只写三块**：
- **能力证据**：做成了什么（资产、规模、存活年数、转型次数）
- **情怀证据**：有没有公开表达过超出赚钱的动机（专访里的原话，不是官网的使命愿景）
- **争议 / 风险**：处罚、投诉、诉讼、股权质押、关联企业套层

> [!danger] 三条禁令
> 1. **不许把公司官方口径（使命 / 愿景 / 荣誉）当个人画像**——那是市场部写的，不是他说的。
> 2. 没有原话就写「无据可查」，不许编、不许从公司历史反推性格。
> 3. 实控人不露面 + 法人另有其人 + 关联企业层层嵌套，本身要作为一条风险写出来。

## 一、先判场景（开头写错，后面全废）

| 场景 | 怎么判定 | 开头 |
|---|---|---|
| **对方先找你** | 猎头来电话、HR 主动打招呼、内推后对方加你 | 可以写「感谢联系」；先接住，再讲 |
| **你主动投递** | 你自己点「立即沟通」、自己搜到岗位投过去 | **禁写「感谢联系」**；直接报身份 + 说对得上的点 |

> [!danger] 最高频错误
> 把「猎头先联系我」那版话术原样套到「我主动投递」的岗位上——开头第一句就是「感谢联系」。
> **动笔前先问一句：这个岗是谁先开口的？**

## 二、首条话术（三条硬规矩）

### 规矩 1：三点，每点一句话，每点对 JD 一句

| 要 | 不要 |
|---|---|
| 3 点，每点一句话 | 三点以上、每点带解释 |
| 每点对应 JD 的一句话 | 泛泛讲能力模型 |
| **直接说亮点** | 解释「其实是接手不是搭建」——没人质疑你，不用辩解 |
| 结尾：发简历 + 一个具体问题 | 结尾：请对方看方案 |

### 规矩 2：不解释、不说缺点

- ❌「会员体系是我接手运营的，不是我从零搭的」——这是替对方**没提的**质疑做辩解，还主动把缺点说出来。
- ✅「接手会员体系运营，靠分层和权益配置把增长目标做成了」——有前置事实，也有结果。

### 规矩 3：数据不是亮点

用户原话：**「数据只是基础能力，它并不是亮点。」**
- 规模事实可以写**一条**（如「企微私域 1600 万用户」），作为身份锚点；
- 不许把数字堆成三个匹配点、用数字论证胜任；
- **团队结果不写成个人结果**，但也不需要加「这是团队结果」的解释——那还是在辩解。只说「做成了」。

**经历怎么挑**（按对方 JD 的主线挑，不是按时间倒序）：
1. **只写撑得住主线的 2 段**，可加 1 段补充；不要把所有经历列一遍；
2. **短于半年的经历不进话术**——问了解释不清，还稀释重点；
3. 同一段经历，对方要什么取什么侧面（要规模取规模，要机制取机制），但**数字不能改**；
4. 不写「口径治理 / A/B test」这类细碎环节——那是执行细节，不是岗位主线。

**全篇结构**：

```
您好，我是 ___，做了 __ 年 ___。
看了这个岗位，有 3 点对得上：
1）___（对 JD 第 __ 句）：一句话 + 一个事实
2）___：一句话
3）___：一句话
简历发您看下。方便的话可以介绍下这个岗位现在团队几个人、汇报给谁？
```

### 排版铁律
**BOSS / 企微聊天框不渲染 Markdown**：`**加粗**` 会原样显示星号，表格会散成一行，`#` 会变成井号，emoji 在部分安卓机显示成方框。
话术必须是**纯文本**：短段落 + `1）2）3）` + 空行分段。排版文件里能用的加粗、表格、色标，**一个都不能带进聊天框**。

## 三、先找人（内推 > 冷启动）

| 顺序 | 找谁 | 怎么找 | 成功率 |
|:--:|---|---|---|
| 1 | 目标团队的人 | 脉脉 / LinkedIn / 前同事 / 行业群 | 最高 |
| 2 | HR / 招聘者 | BOSS 直聊 | 中 |
| 3 | 创始人 / 业务负责人 | 公开邮箱、公众号后台、活动 | 低但质量高 |

> 冷启动投递是最后选项。**先花 20 分钟找内推**，比打磨打招呼话术值钱。
> 内推话术只问两件事：这个岗位现在真实在招吗 / 团队直属领导是什么风格。

## 四、待问清单（3 个只有内部能答的问题）

> 用途：①第一轮就判断岗位真假；②显得你真做过功课。**别问 JD 上写了的**。

| 类型 | 问法 | 想听到什么 |
|---|---|---|
| 权责 | 「这个岗位现在团队几个人、汇报给谁？」 | 有没有 team、是不是虚职 |
| 考核 | 「这个岗位第一年考核什么指标？」 | 拉新 / 转化 / 留存 / 服务履约——判断它真在意什么 |
| 现状 | 「这块现在是有人在做还是空着？」 | 替补还是新增 |

## 五、发方案时机

| 场景 | 动作 |
|---|---|
| 对方回复「发来看看」 | 发 PDF + 一句：一页，重点看断点与 90 天；没用到内部数据 |
| 已读不回 | 2 天后跟进一次，只给新信息，不催 |
| 再没回复 | 关闭，回填投递记录 |

## 八、多轮对话分支（对方追问怎么办）

| 对方说什么 | 怎么回（要点） |
|---|---|
| 行业没做过 | 三件事同构（例：供给不由自己控 / 高客单决策 / 售后履约）+ 一个相邻案例 |
| 薪资期望 | 和 JD 一致 + 反问结构（底薪 / 绩效 / 期权） |
| 要简历 | 立刻发 + 指出第 1 屏对应关键词 |
| 为什么看中我们 | 一个**一号位原话**或公司事实 + 一个战略判断 + 我的同构经验 |
| 为什么离职 / 空窗 | 上家已落地 + 找升级机会 + 随时到岗 |
| 团队管理几年 | 诚实：没带过 10 人正式团队；带过 X 项目，结果 Y，缺的是编制不是方法 |
| 约面试 | 接住 + 确认时间形式 |
| 已读不回 | 2 天后跟一次，只给新信息 |
