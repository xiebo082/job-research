# 常见问题

**1. 怎么「安装」这个 skill？**
不同 AI 安装方式不同：Claude Code 用 `/install` 或放 skills 目录；Codex 放 `.codex/skills`；DeepSeek Harness 用 Skills Manager 导入 ZIP 或复制文件夹。核心是把 `SKILL.md` + `references/` + `examples/` 放进对应 skills 目录。装完验证：说「快速蒸馏：某公司，某岗位」，看它是否先列素材清单 + 缺口 + 5 个问题。

**2. 文件传不上去 / 太长？**
每次只传 2-3 个关键文件；长文档先截取 JD 和目标章节。

**3. 它编数据怎么办？**
回：「把没有来源的数字全部改成未取得，并列出需要我补的 5 个数据。」

**4. 输出太长被截断？**
回：「只输出第 2 个文件，其他先不写。」一次只要一个文件。

**5. 没有联网搜索怎么办？**
把官网/招聘页/评论截图当材料上传；没有材料就让它在缺口里写「未取得」，不要硬编。

**6. 我不是运营岗，能用吗？**
能。把提示词里的「私域/用户增长」替换成你的岗位语言，五层结构不变。

**7. 多久做一家？**
第一家用 3-4 小时跑通，之后 2 小时左右；每周 1-2 家，别贪多。

**8. 方案要不要直接发给 HR？**
先发一页 PDF + 三句话；对方没要，不主动发长文档。

**9. 数据口径不一致怎么办？**
标出口径（出厂价 vs 零售价、全行业 vs 细分品类），同一数字全文只出现一次，其余引用指向它。

**10. 判断和洞察分不清？**
判断 = 5 条固定框架（赚钱/长大/卡哪/押什么/学什么），有命题+支持+反证；洞察 = 反共识、有张力、能改变决策的少数几条（2-4 条）。公司官方口径写出来的，是信息不是洞察。
