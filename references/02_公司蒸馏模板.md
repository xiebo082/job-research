> **排版契约（`references/13_排版规范.md`）**：① 首屏必须是 `> [!important] 一句话结论` 引用块，含"投/条件投/不投"；② 风险/死门槛用 🔴🟡🟢；③ 结论性数字加粗；④ 表格优先；⑤ 末尾必须有交付前对照表；⑥ **全文 ≤300 行**。

## 一句话结论

> [!important] 结论
> 填空：`<公司名> = <起点 → 关键转型 → 当前动作>。它的真瓶颈不是 <表面矛盾>，而是 <被什么锁死>——招 <岗位> 就是这个信号。值得投/条件投/不投，核心岗是 <一句话>。`

**退稿线**：结论里出现"还需了解/待定"即退；必须给"投/条件投/不投"三选一。

| 判定 | 结果 |
|---|---|
| 同一负面出现在「用户面 + 监管/媒体面」 | → 进 **结论** |

## 层 2.6 · 一号位画像（招人主体的一把手 / 直接对外发声的高管）

> 来源：吸收自 `人物志`（输入门槛 + 资料分级 + 必须有反例）。目标不是写传记，是判断**这个人值不值得跟**。

### 先过门槛（不过就降档）

| 手里有什么 | 产出档位 |
|---|---|
| 一手材料 ≥5 万字 / ≥100 条（专访 + 演讲 + 内部信 + 财报问答） | 完整版：五项全写 |
| 有 3–10 条原话，或 2–3 篇专访 | 精简版：只写「一句话判断 + 三句原话 + 反例」 |
| 0 份 | 只写「无据可查」，并写清查了几轮、搜了什么 |

### 资料分级（决定一条证据能不能进结论）

| 级 | 材料 | 用法 |
|---|---|---|
| 1 | 本人著作 / 署名长文 | 可当骨架，可进结论 |
| 2 | 本人专访、演讲、内部信、财报问答 | 可进结论，必带日期 |
| 3 | 口播 / 直播转写 | 只补表达风格与临场判断，不进结论 |
| 4 | 他人转述、书评、二手整理 | **只用于外部视角与补反例，不进结论** |

### 五项必写

1. **一句话判断**：能力（强 / 中 / 弱）和情怀（有据 / 无据）**分开标**，不合并成一句好话
2. **三句原话**：带日期与出处，能看出他的语言习惯
3. **关键决策 2–3 个**：他选了什么、放弃了什么、什么时候转向
4. **反例 1–2 条**：争议、被点名、员工或用户负面。**写不出反例 = 把人神化了，回退重查**
5. **对我的影响**：面试该用什么语言（讲降本还是讲情怀）、哪个问题不能问

### 红线

- 实控人不露面 + 法人另有其人 + 关联企业层层套 → 写进风险，**不写成人格评价**
- 公司官方口径 ≠ 个人画像
- 搜不到写「无据可查 + 搜了几轮 + 搜了哪几个平台」，不许用行业常识补

## 层 5 · 决策
