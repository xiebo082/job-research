## 一句话结论

> 填空：`<公司名> = <起点 → 关键转型 → 当前动作>。它的真瓶颈不是 <表面矛盾>，而是 <被什么锁死>——招 <岗位> 就是这个信号。值得投/条件投/不投，核心岗是 <一句话>。`

**退稿线**：结论里出现"还需了解/待定"即退；必须给"投/条件投/不投"三选一。

## 层 3 · 深度（判断层）

### 五个判断（每条 = 命题 + 支持 + 反证 + 置信度 + 验证）

**判断 1 · 靠什么赚钱**
- 命题 / 支持 / 反证 / 置信度 / 验证

**判断 2 · 靠什么长大**
- 命题 / 支持 / 反证 / 置信度 / 验证

**判断 3 · 现在卡在哪**
- 命题 / 支持 / 反证 / 置信度 / 验证

**判断 4 · 被什么锁死 ⭐（写"公司被什么锁死/还没做/做错"，不是"该做什么"）**
- 命题（洞察）/ 支持 / 反证 / 置信度 / 验证

**判断 5 · 能学到什么（可迁移规律 + 迁移条件）**
- 规律 / 迁移条件

## 层 5 · 决策

### 8 步推演链（一步不漏）

1. 门槛（有无硬死门槛）
2. 招因（为什么现在招）
3. 匹配什么（我有什么）
4. 缺口（我差什么）
5. 缺口是不是他们要买的
6. 主线（我要什么）
7. **机会成本**（不投这家，时间用来干什么，那个选择值多少）
8. 分级（多少分、什么级）
