# 快速蒸馏 · 公司蒸馏标准 v4.0（五层递进 + 退稿规则 + 全链路）

> 2026-11-02 第四次修订。v3.2 把多份 AI 红队评审的 20 条共识写成**可执行退稿规则**；
> v4.0 补齐「顶尖求职顾问 7 件事」：先诊断人 → 算机会成本 → 雇主反向尽调 → 谈薪剧本 → 反向面试 → 入职 90 天 → 判断校准。
> 核心变化：从"研究这家公司"扩到"**诊断你 → 研究公司 → 决策 → 谈判 → 面试 → 入职 → 校准**"全链路。
> 模型来源：一堂《做决策 ROI》（三维度：宽度/深度/高度）+ 行业视角 + 多 AI 评审 + 顶尖求职顾问方法论。

## 〇、全局铁律（任何层都先过这 5 关）

| 铁律 | 规则 | 退稿触发 |
|---|---|---|
| 时效红线 | 关键数据带年份；**优先 6 个月内，拿不到就 1 年内**；>12 个月标「历史口径」，>18 个月不得独撑现状；关键决策看行业公开报道/深度分析 | 一个数字无年份或过期即退 |
| 量纲验算 | ≥2 行交叉验算（会员×ARPU vs 营收），不一致写差异倍数 | 无验算即退 |
| 引用可核验 | 链接开到原文；禁二手聚合站唯一来源；追原始发布日期 | 抽 3 条点不开即退 |
| 单一事实源 | 同一数字全文只出现一次，其余引用指向它 | grep 出两个值即退 |
| 未取得三级降级 | 试过哪 → 卡在哪 → 用什么替代 → 影响哪条结论 | 只有"未取得"三个字即退 |

## 〇·前、第 -1 步：用户诊断（先诊断人，再研究公司）

> v4 新增。不诊断就研究 = 给所有人开同一份药。
> 模板见 `references/10_用户诊断模板.md`。

**必产出 4 样：**

| # | 产出 | 退稿线 |
|:--:|---|---|
| 1 | 求职者档案卡（年限/行业/岗位/规模/薪资底线/通勤/黑名单/空窗） | 缺任一硬约束即退 |
| 2 | 弹药 3 条（带数字或可复现做法） | 写"沟通能力强"即退 |
| 3 | 短板 3 条 + 死门槛清单 | 一条都写不出即退（不可能没有短板） |
| 4 | 主线（钱/成长/稳定/转行）+ 机会成本 | 主线不选即退 |

**3 个可证伪判断**（每条带置信度 + 改判条件）：
- 我能进什么档位的公司
- 我最缺什么（死门槛）
- 我的差异化是什么

**机会成本必须写进每个投递决策**："如果我不投这家，这周时间用来干什么？那个选择值多少？"

## 一、五层结构 + 编号约定

| 编号 | 层 | 问什么 |
|:--:|---|---|
| 层 1 | 广度 | 行业视角（位置 / 上下游 / 周期 / 趋势） |
| 层 2 | 宽度 | 信息层（数据 / 阶段 / 引擎 / 竞争 / 未取得） |
| 层 3 | 深度 | 判断层（5 判断 + 2-4 洞察） |
| 层 4 | 高度 | 视角层（取舍 / 代价 / 二阶后果） |
| 层 5 | 决策 | 决策依据（8 步推演 + 分级） |

**深度档用 D1–D4**（不用 L 表深度）：D1 拍脑袋 → D2 定性优先级 → D3 部分定量 → D4 定量/财务公式。

## 二、层 1 · 广度（行业视角）

四问（a 位置 / b 上下游 / c 周期 / d 趋势），**退稿规则**：

- **五级口径切割**：大盘 → 赛道 → 品类 → 细分 → 渠道，每级给规模 + 增速。
- **趋势时间序列（必做）**：近 10 年（至少 5 年）每年"规模 + 增速"做成表，用数字展示"从高增长到低增长"的拐点；**禁止用"人性化/高端化/DTC"这类文字总结代替数字**。
- **集中度**：CR3/CR10 或头部份额（如头部品牌约 6% 份额）。
- **上下游格局**：上游原料/代工 → 下游渠道/消费者，钱怎么流。
- **≥1 份原始研报**：引用行业报告 / 券商研报 / 上市公司年报，不能只靠"我判断"。
- 周期判断必须给增速数字，不能只写"增长期 / 下滑期"。

---

## 三、层 2 · 宽度（信息层）

5 项（数据表 / 发展阶段 / 引擎瓶颈 / 竞争 / 未取得），**退稿规则**：

- **最近 12–18 个月业务动作 ≥3 条**，带日期来源（否则就是用旧数据写现状）。
- 发展阶段 = **逐年转折点**（每年一件改变方向的事），不是"大阶段"。
- 引擎要过**换名测试**：把公司名换成 3 个同行，引擎还成立 → 重写。
- 引擎三段式：行业结构 × 公司独有 × 当期变化 + 失效条件。

### 3.1 雇主反向尽调（v4 新增，顶尖专家第 3 件事）

> 不只问"这家公司好不好"，要问"**这家公司值不值得我押 3 年**"。
> 公司研究（层 1–2）回答"它是什么"；雇主尽调回答"我进去以后会怎样"。

| 查什么 | 怎么查 | 用来判断 |
|---|---|---|
| **老板轨迹** | 创始人/CEO 近 2 年的公开讲话、采访、内部信 | 他的判断力、战略是否摇摆 |
| **组织稳定性** | 高管变动、裁员传闻、核心岗离职率 | 进去会不会被组织动荡波及 |
| **钱从哪来** | 融资轮次/时间/金额、是否靠补贴、现金流传闻 | 能不能发得出工资、能撑多久 |
| **对人的态度** | 招聘帖反复改 JD、面试流程冗长、欠薪/仲裁记录 | 它把员工当资产还是成本 |
| **业务真实性** | 客户/用户口碑、黑猫投诉、供应商评价 | 它说的增长是不是真的 |

**退稿线**：只写"公司不错/有前景"而没有任何一条可核验的负面或风险 → 尽调没做。

## 四、层 3 · 深度（判断层）

### 4.1 洞察硬门槛

**不要求"必须反共识"，改成三条检验：**

1. **官方等价性测试**：与公司官方口径等价 → 降级回信息层。
2. **改变哪个决策**：这条洞察改变了我哪个决策（投/不投/怎么进/进去做什么）？找不到 → 不合格。
3. **证据 + 竞争解释 + 改判条件**：有证据、有相反解释、写明"什么新证据会推翻我"。

### 4.2 判断 vs 洞察（分开，不混）

- **判断**：5 条固定框架（靠什么赚钱 / 长大 / 卡在哪 / 押什么 / 学什么），每条 = 命题 + 支持 + 反证 + 置信度 + 验证。
- **洞察**：2–4 条（0–1 条即深度层不达标），每条标类型（反共识 / 有张力 / 可迁移）。

### 4.3 判断 4 定义

- 判断 4 必须写"**公司被什么锁死 / 还没做 / 做错**"，不能写"公司该做什么"。
- 写前先查**近 24 个月**公司战略动作（搜"公司名 + 战略/品类/转型"），否则极易把"公司已做的"当"我建议的"。

## 五、层 4 · 高度（视角层）

- **取舍**：这家给什么、要我用什么换。
- **代价**：谁付代价（我 / 公司 / 团队）。
- **二阶后果**：18 个月后会产生什么新问题。
- **换公司失效测试**：这句话换成别家还成立 → 不是"高度"，是套话。

---

## 六、层 5 · 决策

**8 步推演链**（不是直接给结论）：
门槛 → 招因 → 匹配什么 → 缺口 → 缺口是不是他们要买的 → 主线 → **机会成本** → 分级。

- **评分模型统一**：匹配 40% + 薪资 20% + 健康 20% + 主线 20%（固定权重；主线只用于平局优先与 offer 排序，不改权重）。
- **可复算分项表**：每个分项给分 + 理由，总分 = 加权和（不是拍一个数）。
- **0 分不合并**：某维度 0 分单独标出，不许被其他维度平均掉。
- **反转条件**：写"什么证据出现，我会改判（投 ↔ 不投 / 换级）"。
- **机会成本（v4 新增）**：写"不投这家，这周时间用来干什么，那个选择值多少"。S/A 级才值得占用一周，B 级最多一天。

### 分级阈值表（必须写死，不能只给分数）

| 等级 | 加权分 | 做什么 |
|:--:|:--:|---|
| S | ≥85 | 八件套 + 面试包提前准备 + 每 3 家校准 |
| A | 75–84 | 八件套（06 受邀后做）+ 每 5 家校准 |
| B | 60–74 | 01/02/04 + 条件投的 03 |
| C | <60 | 01/02/04（不投，不写方案） |

- **边界 ±3 分取低档**：72 分和 75 分都可能落在边界，取低档，防止分数抖动让用户多做四个文件。
- **任一维度 ≤40 分，不得高于 B**：高分不能掩盖硬伤（这条是「0 分不合并」的执行版）。
- **没有 B+**：只认 S/A/B/C 四档。
- **无简历不算分**：直接给「投 / 条件投 / 不投」三档 + 3 条理由 + 1 条反转条件，标「未叠加个人匹配」。

### 死门槛（否决项，不是评分项）

- **已确认不满足且不可协商**（招聘方写"必须"、且无法用其他经历替代）→ **直接不投**，不参与评分，不给 A/B。
- **未确认**（没 JD、没核实）→ 列「待核验」，不阻塞诊断。
- **偏好 / 可协商**（薪资区间有交集、学历差一档）→ 不算死门槛，写进风险。
- 薪资写法：「区间有交集，固定部分与实际可得报价未知」，不写「符合底线」。

## 七、深度分级 D1–D4（实事求是）

| 决策占用 | 该做到 |
|---|---|
| 2 小时以内 | D1 拍脑袋 |
| 一周以内 | D2 排优先级 |
| 一个月以上（选 offer） | D3–D4 定量 |

## 八、三条轨

- **筛选轨**：所有公司做层 1–2 + 打分（快速过滤，不深挖）。
- **练习轨**：业务研究不设"永远做深"，按**信息价值**决定投入——能沉淀可迁移规律才深挖，否则止步层 2。
- **offer 轨**：S/A 做满层 1–5 + 动作包 + 面试包；B 做层 1/2/4；C 只做层 1–2。

**止步规则（防过度研究）**：一旦结论是「不投」且用户没说「进练习轨」，**立即停止**——不再联网补数据、不再写长文件，只留一句"结论 + 原因 + 什么情况下回来看"。
