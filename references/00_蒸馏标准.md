# 快速蒸馏 · 公司蒸馏标准 v3.2（五层递进 + 退稿规则）

> 2026-11-02 三次修订。v3.2 把多份 AI 红队评审的 20 条共识，写成**可执行退稿规则**。
> 核心变化：标准不再只写"要写什么"，而是写"**写成什么样算达标、不达标怎么退稿**"。
> 模型来源：一堂《做决策 ROI》（三维度：宽度/深度/高度）+ 行业视角 + 多 AI 评审。

---

## 〇、全局铁律（任何层都先过这 5 关）

| 铁律 | 规则 | 退稿触发 |
|---|---|---|
| 时效红线 | 关键数据带年份；**优先 6 个月内，拿不到就 1 年内**；>12 个月标「历史口径」，>18 个月不得独撑现状；关键决策看行业公开报道/深度分析 | 一个数字无年份或过期即退 |
| 量纲验算 | ≥2 行交叉验算（会员×ARPU vs 营收），不一致写差异倍数 | 无验算即退 |
| 引用可核验 | 链接开到原文；禁二手聚合站唯一来源；追原始发布日期 | 抽 3 条点不开即退 |
| 单一事实源 | 同一数字全文只出现一次，其余引用指向它 | grep 出两个值即退 |
| 未取得三级降级 | 试过哪 → 卡在哪 → 用什么替代 → 影响哪条结论 | 只有"未取得"三个字即退 |

## 一、五层结构 + 编号约定

| 编号 | 层 | 问什么 |
|:--:|---|---|
| 层 1 | 广度 | 行业视角（位置 / 上下游 / 周期 / 趋势） |
| 层 2 | 宽度 | 信息层（数据 / 阶段 / 引擎 / 竞争 / 未取得） |
| 层 3 | 深度 | 判断层（5 判断 + 2-4 洞察） |
| 层 4 | 高度 | 视角层（取舍 / 代价 / 二阶后果） |
| 层 5 | 决策 | 决策依据（7 步推演 + 分级） |

**深度档用 D1–D4**（不用 L 表深度）：D1 拍脑袋 → D2 定性优先级 → D3 部分定量 → D4 定量/财务公式。

---

## 二、层 1 · 广度（行业视角）

四问（a 位置 / b 上下游 / c 周期 / d 趋势），**退稿规则**：

- **五级口径切割**：大盘 → 赛道 → 品类 → 细分 → 渠道，每级给规模 + 增速。
- **趋势时间序列（必做）**：近 10 年（至少 5 年）每年"规模 + 增速"做成表，用数字展示"从高增长到低增长"的拐点；**禁止用"人性化/高端化/DTC"这类文字总结代替数字**。
- **集中度**：CR3/CR10 或头部份额（如头部品牌约 6% 份额）。
- **上下游格局**：上游原料/代工 → 下游渠道/消费者，钱怎么流。
- **≥1 份原始研报**：引用行业报告 / 券商研报 / 上市公司年报，不能只靠"我判断"。
- 周期判断必须给增速数字，不能只写"增长期 / 下滑期"。

---

## 三、层 2 · 宽度（信息层）

5 项（数据表 / 发展阶段 / 引擎瓶颈 / 竞争 / 未取得），**退稿规则**：

- **最近 12–18 个月业务动作 ≥3 条**，带日期来源（否则就是用旧数据写现状）。
- 发展阶段 = **逐年转折点**（每年一件改变方向的事），不是"大阶段"。
- 引擎要过**换名测试**：把公司名换成 3 个同行，引擎还成立 → 重写。
- 引擎三段式：行业结构 × 公司独有 × 当期变化 + 失效条件。

---

## 四、层 3 · 深度（判断层）

### 4.1 洞察硬门槛

**不要求"必须反共识"，改成三条检验：**

1. **官方等价性测试**：与公司官方口径等价 → 降级回信息层。
2. **改变哪个决策**：这条洞察改变了我哪个决策（投/不投/怎么进/进去做什么）？找不到 → 不合格。
3. **证据 + 竞争解释 + 改判条件**：有证据、有相反解释、写明"什么新证据会推翻我"。

### 4.2 判断 vs 洞察（分开，不混）

- **判断**：5 条固定框架（靠什么赚钱 / 长大 / 卡在哪 / 押什么 / 学什么），每条 = 命题 + 支持 + 反证 + 置信度 + 验证。
- **洞察**：2–4 条（0–1 条即深度层不达标），每条标类型（反共识 / 有张力 / 可迁移）。

### 4.3 判断 4 定义

- 判断 4 必须写"**公司被什么锁死 / 还没做 / 做错**"，不能写"公司该做什么"。
- 写前先查**近 24 个月**公司战略动作（搜"公司名 + 战略/品类/转型"），否则极易把"公司已做的"当"我建议的"。

---

## 五、层 4 · 高度（视角层）

- **取舍**：这家给什么、要我用什么换。
- **代价**：谁付代价（我 / 公司 / 团队）。
- **二阶后果**：18 个月后会产生什么新问题。
- **换公司失效测试**：这句话换成别家还成立 → 不是"高度"，是套话。

---

## 六、层 5 · 决策

**7 步推演链**（不是直接给结论）：
门槛 → 招因 → 匹配什么 → 缺口 → 缺口是不是他们要买的 → 主线 → 分级。

- **评分模型统一**：匹配 40% + 薪资 20% + 健康 20% + 主线 20%（唯一权重，健康维度不再消失）。
- **可复算分项表**：每个分项给分 + 理由，总分 = 加权和（不是拍一个数）。
- **0 分不合并**：某维度 0 分单独标出，不许被其他维度平均掉。
- **反转条件**：写"什么证据出现，我会改判（投 ↔ 不投 / 换级）"。
- 死门槛：1 条 → 最高 A；2 条+ → 最高 B。

## 七、深度分级 D1–D4（实事求是）

| 决策占用 | 该做到 |
|---|---|
| 2 小时以内 | D1 拍脑袋 |
| 一周以内 | D2 排优先级 |
| 一个月以上（选 offer） | D3–D4 定量 |

---

## 八、三条轨

- **筛选轨**：所有公司做层 1–2 + 打分（快速过滤，不深挖）。
- **练习轨**：业务研究不设"永远做深"，按**信息价值**决定投入——能沉淀可迁移规律才深挖，否则止步层 2。
- **offer 轨**：S/A 做满层 1–5 + 动作包 + 面试包；B 做层 1/2/4；C 只做层 1–2。
