# 口碑三面：用人口碑 / 用户口碑 / 行业口碑

> 一句话：口碑不是给公司打分，是回答三个**不同**问题——**待得下去吗 / 产品能打吗 / 简历上写它会不会减分**。
> 三面必须分开写。混着写 = 没查。

## 一、三面分别回答什么

| 面 | 回答的问题 | 判断的对象 | 用途 |
|---|---|---|---|
| **用人口碑**（员工/前员工） | 这家公司值不值得待 | 组织：强度、KPI、管理、流动率、薪资兑现 | 决定你能不能忍 |
| **用户口碑**（付钱的一方） | 这家公司的产品能不能打 | 产品：质量、履约、售后、投诉结构 | 决定你进去能干什么活 |
| **行业口碑**（同行/媒体/监管） | 这家公司正不正经 | 合规与地位：处罚、点名、诉讼、行业位置 | 决定简历上写它会不会减分 |

> **最常见的错**：拿用户投诉去证明「这公司不行」。用户投诉多，可能只是规模大。
> **正确做法**：三面各自下结论，再看它们**是否互相印证**（见第三节第 3 条）。

## 二、渠道清单（按成本从低到高逐层取）

### 用人口碑
- 脉脉（搜「公司名 + 部门」，看在职/离职帖）
- 看准网 / 职友集（评分、面经、薪资爆料）
- 知乎「在 XX 工作是什么体验」；小红书「XX 离职 / XX 裁员 / XX 加班」
- BOSS 公司主页的在职评价
- 领英：搜同岗位，看**平均在职时长**（换得勤 = 流动率高的间接证据）
- **招股书 / 年报里的员工数据**：社保公积金是否足额缴纳、员工成本占比、股权激励池（公司自己披露的最诚实）

### 用户口碑
- 黑猫投诉（按公司全名搜：**总量 / 解决率 / 投诉类型分布**三项一起看）
- 应用商店评分 + 差评关键词
- 小红书 / 抖音 / 贴吧 / 豆瓣小组
- **行业专属端**：司机端（货拉拉、滴滴）、商家端（美团、饿了么）、维修师傅端（万师傅类）、供应商端
- 天眼查 / 企查查「司法风险」「行政处罚」页

### 行业口碑
- 市场监管总局 / 地方市监局处罚公告（**最硬的一档**）
- 国家企业信用信息公示系统
- 中国裁判文书网（看**案由分布**，不看单案）
- 权威媒体深度报道：36氪、晚点、财新、经济观察报、北京商报、蓝鲸财经
- **招股书「风险因素」章**：公司自己承认的风险，比任何第三方评价都可信
- 竞对 / 上下游的公开评价（行业峰会、访谈、合作公告）

## 三、四条判断规则

1. **看结构不看单条**
   把投诉按类型分：退款 / 质量 / 履约 / 客服 / 虚假宣传 / 催收 / 信息泄露。看**分布**和**解决率**，不看最刺眼的那一条。

2. **证据五级（决定能写进哪一栏）**
   | 等级 | 证据 | 能写进哪 |
   |:--:|---|---|
   | 1 | 监管处罚、法院判决 | **结论** |
   | 2 | 权威媒体点名报道 | **结论** |
   | 3 | 批量同类投诉（≥20 条） | 风险（高置信度） |
   | 4 | 平台评分 / 供应商案例 | 风险（中） |
   | 5 | 匿名单条爆料 | 只作线索，标注「未验证」 |

3. **交叉验证（三面交叉表）**
   | 出现在几个面 | 怎么定 |
   |---|---|
   | 用户面 + 监管/媒体面 同时出现 | **真问题**，进结论 |
   | 只用人口碑差 | 可能是「强度大但合法」，进风险，别上升到「公司有问题」 |
   | 只有用户口碑差 | 先查是不是**行业通病**；是通病就不算它的问题 |
   | 只有行业口碑差（被点名/被罚） | 进结论，这直接影响简历价值 |

4. **必须落到「对我有什么影响」**
   每条口碑最后一句必须回答：这会影响我的**投递决策 / 面试答法 / 简历叙事**中的哪一个。

## 六、三条红线

1. **搜不到就写「未取得」**，并写清搜了哪几个平台、影响了哪条判断。口碑是最容易编的一块。
2. **匿名爆料只能当线索**，不能当结论；写进文件时必须标「未验证」。
3. **不许把行业通病写成这家公司的问题**。先问一句：同行是不是也这样？是 → 写「行业性」，不是 → 才写「公司性」。

## 七、两个真实范例（本仓库的实际判断）

**青年优品（分期商城）**
- 用户面：黑猫多条——强制绑定分期、不许退机、冒充法院短信、明租实贷 + 软暴力催收
- 行业面：北京商报 2025-09 点名「租机套现」产业链、2025-07 虚假宣传罚 2 万、2026-04 小程序违规收集个人信息被通报
- 用人面：未取得
- → **两面交叉**（用户 + 监管/媒体）→ 结论：**不值得主动投**
- 注意：当时还查了正面——租机 25 亿规模、经济观察报口径「溢价 30% + 年利率 24% 内」在司法保护上限内。**要正反并列。**

**SKG（未来穿戴）**
- 用户面：有赞客户案例，私域销售额 +69%、老客 +274%（**供应商口径，等级 4**）
- 行业面：2018 年颈椎按摩仪市占 68%、牵头行业标准、摩根士丹利亿元投资（正面为主）
- 用人面：招股书披露社保公积金未足额缴纳、上市前夫妻分红 2.35 亿（等级 1–2）
- → 反差结论：**公司很能打，但员工侧有笔账没结清** → 面试可以问「社保和公积金的缴纳口径按什么标准」

> 这个例子说明：**三面结论不一致是常态，不是查错了。** 不一致本身就是最有价值的判断——它能让你在面试里问出别人问不出的问题。
