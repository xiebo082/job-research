# 面试包模板（受邀后触发 · 作答 + 谈薪 + 反向面试 + 入职 90 天）

> v4 新增。前面五层解决「投不投、怎么进」，这一份解决「怎么答、进去谈多少钱、进去是不是坑、进去怎么活」。
> 触发条件：对方明确约面试（不是"已读"）。
> 四段：① 作答准备（把你的经历变成证据）→ ② 反向面试（验公司真假）→ ③ 谈薪（再谈钱）→ ④ 入职 90 天（最后怎么活）。

---

## 〇、作答准备：把「负责过」变成「我做过、有证据」

> 面试官只信三样：你**具体做了什么**、**结果怎么变**、**如果重来你会改什么**。
> 不要背答案，背**结构**：问题 → 背景 → 我的动作 → 证据 → 追问预案。

### 0.1 准备 5 个故事（覆盖 80% 面试题）

| 故事 | 对应题型 | 讲什么 |
|---|---|---|
| 从 0 到 1 | "你怎么搭一个体系" | 起点多乱 → 你先做什么 → 结果 |
| 救火 | "你怎么处理危机/客诉" | 出事时你在哪 → 先止血 → 复盘 |
| 不配合 | "跨部门推不动怎么办" | 对方为什么不动 → 你换了什么筹码 |
| 失败 | "讲一次失败" | 你判断错在哪 → 代价 → 后来怎么改 |
| 数据 | "你怎么证明有效" | 指标怎么定 → 口径怎么防作弊 → 涨了多少 |

### 0.2 每个故事五格（写下来，不背）

| 格 | 写什么 | 反例 |
|---|---|---|
| 问题 | 当时要解决什么，为什么难 | "负责会员运营"（不是问题） |
| 我的动作 | 我**个人**做了什么（不是团队） | "我们做了…"（面试官听不出你） |
| 证据 | 数字 + 口径 + 时间 | "提升很多"（没数字） |
| 追问预案 | 最可能被追问的 3 个问题 | 无 |
| 如果重来 | 你会改什么（显示判断力） | 无 |

### 0.3 高频追问预案（提前想好，别现场编）

- "这个数字是你做的，还是团队做的？" → 说清你负责的那一段。
- "口径怎么定的？有没有可能虚高？" → 说出你怎么防作弊。
- "如果预算砍一半，你还怎么做？" → 显示优先级判断。
- "你为什么离开上一家？" → 说事实 + 你要什么，不贬前雇主。
- "你还有什么问题？" → 用第二节的反向面试题。

## 一、反向面试：先验公司，再谈钱

面试是双向的。你问的问题，比答的问题更能暴露水平，也能救你半年。

### 1.1 问老板 / 业务负责人（验业务真假）

| 要验证 | 问法 |
|---|---|
| 业务真问题 | "这个岗位现在最想解决的**一个**问题是什么？如果解决不了，半年后会怎样？" |
| 招人原因 | "这个岗位是新增还是补位？上一个做这岗的人为什么走/去哪了？" |
| 决策链 | "这件事最后谁拍板？我需要说服几个人？" |
| 资源 | "预算/人手/系统，现在有哪些，缺哪些？" |
| 成功标准 | "半年后你用什么判断我做得好？有数字吗？" |

> **陷阱信号**：回答全是"我们要做私域/要增长"却没有**一个具体数字或具体卡点** → 岗位没想清楚，进去就是背锅。

### 1.2 问 HR（验岗位真假）

| 要验证 | 问法 |
|---|---|
| 岗位真实性 | "这个岗位 open 多久了？面到第几轮了？" |
| 薪资结构 | "这个薪资是固定 + 绩效的什么比例？绩效怎么算？" |
| 编制 | "这个岗位是正式编制还是外包/项目制？" |
| 试用期 | "试用期考核标准是什么？有书面目标吗？" |
| 汇报线 | "我汇报给谁？他带几个人？" |

> **陷阱信号**：薪资构成说不清、编制含糊、试用期"看表现" → 先别接。

### 1.3 问未来同事（验日常真假，可选）

- "你们一天里最花时间的事是什么？"
- "这个团队最近一次吵架是因为什么？"
- "如果我来了，你希望我第一个月先搞定什么？"

### 1.4 红线清单（出现任意一条，重新考虑）

- [ ] 岗位 open 超过 6 个月还在招
- [ ] 老板说不清"最想解决的一个问题"
- [ ] 上一个做这岗的人干了不到 1 年
- [ ] 薪资结构说不清 / 编制含糊
- [ ] 试用期考核没有书面目标
- [ ] 面试全程只问"你能不能加班/抗压"

## 二、谈薪剧本：先让对方确认价值，再报价

> 核心原则：**谈薪不是讨价还价，是让对方先承认"你能解决那个问题值多少钱"。**
> 顺序错了，后面全错。

### 2.1 谈薪前必须算清的 4 个数

| 数 | 怎么算 | 用途 |
|---|---|---|
| **BATNA**（最佳替代方案） | 手上最好的另一个 offer / 继续找的预期 / 空窗能撑几个月 | 你的底线，低于它就拒 |
| **目标价** | 市场同岗 P50–P75（看招聘平台 + 同行口述） | 你要报的锚 |
| **可接受区间** | 目标价 ~ 底线之间 | 谈判空间 |
| **总包** | 月薪 × 月数 + 奖金 + 补贴 + 期权 | 别只盯月薪 |

> **没有 BATNA 就别硬谈**：先拖时间、多拿一个 offer，再回来谈。

### 2.2 报价顺序（关键，别搞反）

| 顺序 | 做法 | 为什么 |
|:--:|---|---|
| 1 | 先让对方说预算区间 | 谁先报价谁先暴露 |
| 2 | 对方不说，你报**区间**不报单点 | "我预期 25–30K，具体看总包结构" |
| 3 | 先谈**价值**再谈**数字** | "我能解决 X，这个在你们业务里值多少？" |
| 4 | 用**总包**谈，不用月薪谈 | 月薪谈不动，用签字费/期权/涨薪节点补 |
| 5 | 拿到口头 offer 后，**书面确认** | 防"口头 30K，合同 25K" |

### 2.3 话术模板（直接改数字用）

**开场（被问期望薪资）**：
> "我主要看总包和成长空间。这个岗位我理解核心是解决 <具体问题>，如果这块做成了，对你们的价值大概是 <量级>。所以我的预期是 <区间>，具体可以看结构。"

**对方压价（"我们预算只有 X"）**：
> "理解预算有框架。我想确认一下：如果我把 <可验证的成果> 在 3 个月内做出来，薪资有没有调整机制？比如试用期后复盘、或者半年调薪？"

**对方问"你最低能接受多少"**：
> "我更关心的是这个岗位能不能做成。薪资上我的底线是 <底线>，但如果有成长空间和明确的调薪节点，我可以谈。"

**拿到 offer 后（确认细节）**：
> "谢谢！我想确认几个细节：月薪基数、绩效比例、发薪月数、试用期薪资比例、调薪节点。方便发一份书面 offer 吗？"

### 2.4 僵局处理：钱谈不动，换什么

| 换什么 | 怎么提 | 适用 |
|---|---|---|
| 签字费 | "月薪按你们的来，能不能加一笔签字费补差额？" | 预算卡死但想要你 |
| 涨薪节点 | "试用期后按 <标准> 复盘调薪，写进 offer？" | 对方说"以后会涨" |
| 职级/头衔 | "薪资不变，职级能不能给到 <更高>？" | 为下一份跳槽铺路 |
| 期权/奖金 | "现金少一点，期权/项目奖金能不能补？" | 早期公司 |
| 弹性/资源 | "薪资按你们的，能不能给 <预算/人手/培训>？" | 想做事的人 |

> **别做的事**：编一个假 offer 压价（背调会穿）、当场答应（显得没底线）、只谈月薪不谈总包。

## 三、入职 90 天：怎么活下来，而不是怎么表现

> 面试通过只是拿到入场券。前 90 天决定你能不能过试用期、能不能站稳。

### 3.1 0–30 天：只做三件事，别急着改

| 动作 | 具体做什么 | 产出 |
|---|---|---|
| 摸人 | 和每个关键角色聊 30 分钟：他们最痛什么、最怕什么、谁说了算 | 一张「人-事-权」地图 |
| 摸流程 | 把一个核心流程从头走一遍（自己动手，不听汇报） | 一张现状流程图 + 3 个卡点 |
| 摸数据 | 要一份近 6 个月的核心数据，自己算一遍，看和汇报口径差多少 | 一份「口径差异表」 |

> **30 天内不要提大改**。你还没资格改，先证明你看得懂。

### 3.2 30–60 天：拿一个「小、快、可验证」的成果

选一个**别人没做、你能做、2 周能出结果**的事：
- 一个卡了很久的小流程，你理顺了；
- 一份没人算清的数据，你算清了；
- 一个反复出错的环节，你定了标准。

成果要**能被看见**：发在群里、写成一页纸、在周会上讲一次。

### 3.3 60–90 天：把成果变成机制

- 把 quick win 写成 SOP / 看板 / 复盘模板；
- 让它**不依赖你**也能跑（否则你只是个大号执行）；
- 在试用期复盘时，用「我做了什么 → 结果是什么 → 沉淀了什么」讲。

### 3.4 90 天后：提第二阶段

- 基于前 90 天的真实数据，提一个**有依据**的扩张计划；
- 这时候你才有资格说"下一步该做什么"。

### 3.5 前 90 天的四个坑

| 坑 | 表现 | 怎么避 |
|---|---|---|
| 站队 | 太快靠近某一派 | 前 30 天对所有人保持等距 |
| 背锅 | 接了别人做砸的项目 | 接之前先问"为什么是我""资源给不给" |
| 越级 | 绕过直属领导找老板 | 所有事走汇报线，除非有明确授权 |
| 抢功 | 把团队的成果说成自己的 | 说"我们"，但保留自己那部分的证据 |
