# 岗位类型骨架库

> 来源：从 `full-spectrum-distiller` 的 `skeleton-library.md`（按关键词精确匹配到行业骨架）吸收改造。FSD 按**行业**匹配，这里按**岗位类型**匹配——因为同一岗位在不同行业，要查的东西 80% 一样。
> 用法：第 3 步岗位蒸馏**先匹配类型**，套对应骨架；做完把新案例追加进「已做过」列，同类累计 ≥3 家后回补骨架。

---

## 一、命中规则（任一关键词命中即停）

| 命中关键词（任一） | 类型 | 骨架 |
|---|---|---|
| 企微 / 私域 / 社群 / 企业微信 / SCRM / 微信生态 | 私域 / 企微运营 | A |
| 会员 / 积分 / 等级 / 权益 / 复购 / LTV / 付费会员 | 会员运营 | B |
| 小程序 / 站内转化 / 活动页 / 商城 / 转化率 / GMV | 小程序 / 站内转化 | C |
| 策略 / 经营分析 / 供需 / 补贴 / 定价 / UE / 指标 / 口径 | 策略 / 经营分析 | D |
| 增长 / 拉新 / 裂变 / 留存 / 召回 / 内容 / UGC / 海外社群 | 用户增长 / 内容 | E |
| **其他** | 落回「通用」 | 查 01 五层即可，不用套骨架 |

## 二、五个骨架

### 骨架 A · 私域 / 企微运营

| 项 | 内容 |
|---|---|
| 必查 6 项 | ①现有私域规模与增速 ②成交落点（企微→哪成交）③售后/客服链路是否与私域联动 ④门店/导购/师傅等线下触点关系 ⑤AI 工具现状（有无 AI 客服/自动触达）⑥加粉钩子是什么 |
| 打分侧重 | 企微规模与分层 40% + 会员/复购 25% + 服务联动 20% + 行业 15% |
| 话术主线 | 企微规模（一条锚点，不堆数字）+ 分层触达 + 服务动作变规则 |
| 常见死门槛 | 行业 gap（如医疗/跨境）；「带团队」；「从 0 搭会员」 |
| 已做过 | 平安好医生（服务型私域）、诺特兰德、豆柴、SKG、蕉下、全棉 |

### 骨架 B · 会员运营

| 项 | 内容 |
|---|---|
| 必查 6 项 | ①会员盘子（免费/付费分层）②付费会员新增与增速 ③权益成本 ④复购口径（月复购/年复购）⑤积分体系是否已有 ⑥会员体系是接手还是新建 |
| 打分侧重 | 会员全生命周期 40% + 分层/权益配置 25% + 数据 20% + 行业 15% |
| 话术主线 | 接手会员体系达成增长（有前置也有结果）+ 分层权益配置 |
| 常见死门槛 | 「从 0 搭」要求（他不满足）；纯拉新不带会员；行业 0 经验 |
| 已做过 | 迪阿股份、沐腾、全棉、诺特兰德 |

### 骨架 C · 小程序 / 站内转化

| 项 | 内容 |
|---|---|
| 必查 6 项 | ①小程序在公司私域里的角色 ②流量入口（企微/公众号/搜索）③首页/活动页/支付页谁主导 ④转化链路断点 ⑤活动机制（大促/会员日/裂变）⑥复购与留存设计 |
| 打分侧重 | 站内转化体系 35% + 活动策划 25% + 用户分层/会员 25% + 行业 15% |
| 话术主线 | 小程序站内转化（万师傅企微用户最后到小程序成交）+ 会员复购 |
| 常见死门槛 | 「3 年小程序经验」vs 他 2 年（差 1 年方向对可谈）；纯投放岗 |
| 已做过 | 迪阿股份、SKG |

### 骨架 D · 策略 / 经营分析

| 项 | 内容 |
|---|---|
| 必查 6 项 | ①城市/区域/UE 模型 ②指标口径现状（是否混乱）③补贴/定价策略 ④供需关系与匹配 ⑤经营报表体系 ⑥这岗参与目标制定还是只做报表 |
| 打分侧重 | 数据分析与指标口径 40% + 经营分析报告 25% + 跨部门 20% + 行业 15% |
| 话术主线 | 把没标准的事定成规则（口径统一）+ 推得动跨部门 |
| 常见死门槛 | 「2 年策略/经营分析经验」他没有；「补贴/定价」0 经验；只做报表无决策权 → 不去 |
| 已做过 | 贝壳、货拉拉×2 |

### 骨架 E · 用户增长 / 内容

| 项 | 内容 |
|---|---|
| 必查 6 项 | ①增长引擎（内容/投放/裂变）②内容矩阵 ③拉新留存召回机制 ④分层运营 ⑤数据口径 ⑥是否含海外/特定圈层 |
| 打分侧重 | 机制/SOP 体系化 35% + 分层/积分 25% + 渠道实操 25% + 行业 15% |
| 话术主线 | 分层 + 机制搭建 + 反馈变产品动作（慎用数据） |
| 常见死门槛 | 海外社群平台/英文；特定圈层（园艺/欧美）；纯内容岗 |
| 已做过 | 乐动（海外，不投）、万兴、翼鸥、歪麦、青年优品 |

## 三、沉淀规则（从 FSD 吸收）

- 同一类型第 2 家：用上一次的必查 6 项 + 打分表增量微调，不从零列。
- 同类累计 ≥3 家且反复打补丁：回补本骨架，追加「常见死门槛」。
- 匹配不到类型：落「通用」，走 01 五层即可，不硬套。
