# job-research · 快速蒸馏求职工作流

> 求职是一连串可证伪的决策，不是一次投递。本工作流从「诊断你是谁」开始，到「研究公司、评估能不能进、谈薪、反向面试、入职 90 天成事」，最后把每次判断的结果回填校准——目标是提高「约面 + 通过 + offer + 入职活下来」的概率，而不是产出一份漂亮的方案。

## 一句话定位

把求职从「海投简历」变成「对目标公司做一次结构化尽调 + 一页投递方案 + 一套可校准的决策」，用「方法」而不是「运气」提高约面率和入职后的判断力。

## 它解决什么问题

| 痛点 | 本工作流怎么解 |
|---|---|
| 海投没回复 | 一页差异化投递方案 + 六段式打招呼，让 HR 看到「你真的研究过」 |
| 面试被问倒 | 公司蒸馏五层，把公司从行业到决策摸透；反向面试提前问穿对方 |
| 谈薪被压 | BATNA + 锚定 + 确认价值 + 僵局 5 选项 |
| 入职踩坑 | 判断层 + 高度层 + 入职 90 天，提前看「最可能错在哪」 |
| 判断越做越蠢 | 决策日志 + 结果回填 + 每 5 家校准，把经验变成规则 |
| 长期不找工作也荒废 | 业务研究轨，不投也研究，练业务思考 |

## 目标用户

- 求职中的运营/市场/产品等岗位的人
- 想「看懂一家公司」的人（不限于求职）
- 想把自己的判断「校准得更准」的人

## 安装

不同 AI 安装方式不同。核心是：**把 `SKILL.md` 作为主提示词，`references/` 和 `examples/` 作为它引用的资料**，放在 AI 能读到的位置。

| AI | 怎么装 | 说明 |
|---|---|---|
| Claude Code | `~/.claude/skills/job-research/`（手动复制整个目录） | 社区插件市场的 `/plugin install` 是另一个机制，本仓库**不提供** `/install` 命令 |
| Codex | `.agents/skills/job-research/`（项目级）或 `~/.agents/skills/`（用户级） | 以你本机 Codex 实际支持的 skills 路径为准 |
| DeepSeek Harness | Skills Manager 导入 ZIP，或复制到 `~/.dsh/skills/job-research/` | 仓库不附带 ZIP（`.gitignore` 忽略 `*.zip`），导入时请自行打包当前目录 |
| 其他 AI | 把 `SKILL.md` + `references/00_蒸馏标准.md` + JD 一起粘贴 | 只能走"快速判断"，文件读写和联网能力会退化 |

**运行前提**（不满足也能跑，但要降级）：

| 能力 | 必需？ | 没有会怎样 |
|---|---|---|
| 文件读写 | 必需 | 不能落盘，只能把内容贴在对话里 |
| 联网搜索 | 必需 | 时效数据拿不到，全标「未取得」 |
| Chrome + pdfinfo | 可选 | 不能把 03 投递方案导出 PDF，改出单页 Markdown |

**装完验证**：说「快速蒸馏：某公司，某岗位」。
- 期望：先问简历；若你说没有，它能**直接给快速判断**（不为难你）。
- 若它卡住只要简历、不往下走 → 装的是旧版，或模型没读到 SKILL.md 的「三分支」段。

**隐私**：发简历前先遮手机号、身份证号、住址、前客户名；`00_用户诊断.md` 用代号，不写真名。

## 用法

**第一次用（只做一次）：**

```
你好，我先发简历给你，帮我做用户诊断。
[附简历 PDF / Word / 图片 / 文字]
```

AI 会：读简历 → 提取事实层 → 只问简历里没有的 5 件事 → 产出 `00_用户诊断.md`。

**之后每家公司：**

```
快速蒸馏：<公司名>，<岗位名>
```

AI 会引用已有的 `00_用户诊断.md`，不再重复问。

**没简历 / 不想发简历时：**

```
快速蒸馏：<公司名>，<岗位名>
我没有简历，先告诉我这家值不值得去。
```

AI 会只做公司层 + 岗位层（01 层 1–2 + 02 的 JD 反拆/门槛/真实性/HR 第一屏），给「投 / 条件投 / 不投 + 3 条理由 + 1 条反转条件」，**不给匹配分**，标「未叠加个人匹配」。这不是残缺，是诚实：没有你的数据，硬算匹配就是拍脑袋。

产出八件套（按等级分闸，不是每家公司都做满）：

| # | 文件 | 何时做 |
|:--:|---|---|
| 00 | 用户诊断 | 第一次用做一次，之后复用；没简历可跳过 |
| 01 | 公司蒸馏（五层） | 全部；无简历只做层 1–2 + 决策 |
| 02 | 岗位蒸馏 | 全部；无简历只做 JD 反拆/门槛/真实性/第一屏 |
| 03 | **投递方案**（对外 A4） | S/A 必做；B 条件投才做；C 不做 |
| 04 | 证据附录 | 全部 |
| 05 | 投递动作包 | S/A/B（要投就做） |
| 06 | 面试包（作答+反向面试+谈薪+90天） | 受邀后 |
| 07 | 复盘与校准 | 投递/面试后 |

等级阈值：S ≥85 / A 75–84 / B 60–74 / C <60；边界 ±3 取低档；任一维度 ≤40 不得高于 B；没有 B+。

## 方法论概览

- **五层结构**：广度（行业视角）→ 宽度（信息）→ 深度（判断+洞察）→ 高度（视角）→ 决策（8 步推演 + 机会成本）。
- **第 -1 步**：先诊断人（弹药/短板/死门槛/主线/机会成本/3 个可证伪判断）。
- **5 条铁律**：时效红线 / 量纲验算 / 引用可核验 / 单一事实源 / 未取得三级降级。
- **评分模型**：匹配 40% + 薪资 20% + 健康 20% + 主线 20%，可复算，0 分不合并。
- **三轨分流**：筛选轨（快速过滤）/ 练习轨（按信息价值决定投入）/ offer 轨（做满）。
- **校准闭环**：决策日志 → 结果回填 → 每 5 家校准 → 更新判断规则。
