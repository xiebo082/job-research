# job-research · 快速蒸馏求职工作流

> 求职是一连串可证伪的决策，不是一次投递。本工作流从「诊断你是谁」开始，到「研究公司、评估能不能进、谈薪、反向面试、入职 90 天成事」，最后把每次判断的结果回填校准——目标是提高「约面 + 通过 + offer + 入职活下来」的概率，而不是产出一份漂亮的方案。

## 一句话定位

把求职从「海投简历」变成「对目标公司做一次结构化尽调 + 一页投递方案 + 一套可校准的决策」，用「方法」而不是「运气」提高约面率和入职后的判断力。

## 它解决什么问题

| 痛点 | 本工作流怎么解 |
|---|---|
| 海投没回复 | 一页差异化投递方案 + 六段式打招呼，让 HR 看到「你真的研究过」 |
| 面试被问倒 | 公司蒸馏五层，把公司从行业到决策摸透；反向面试提前问穿对方 |
| 谈薪被压 | BATNA + 锚定 + 确认价值 + 僵局 5 选项 |
| 入职踩坑 | 判断层 + 高度层 + 入职 90 天，提前看「最可能错在哪」 |
| 判断越做越蠢 | 决策日志 + 结果回填 + 每 5 家校准，把经验变成规则 |
| 长期不找工作也荒废 | 业务研究轨，不投也研究，练业务思考 |

## 目标用户

- 求职中的运营/市场/产品等岗位的人
- 想「看懂一家公司」的人（不限于求职）
- 想把自己的判断「校准得更准」的人

## 安装

不同 AI 安装方式不同，核心是把 `SKILL.md` + `references/` + `examples/` 放进对应 skills 目录：

| AI | 方式 |
|---|---|
| Claude Code | 放 `~/.claude/skills/` 或 `/install` |
| Codex | 放 `.codex/skills/` |
| DeepSeek Harness | Skills Manager 导入 ZIP，或复制到 `~/.dsh/skills/` |
| 其他 AI | 把 SKILL.md 全文 + 标准 + JD 一起粘贴，当作提示词用 |

装完验证：说「快速蒸馏：某公司，某岗位」，看它是否先做用户诊断，再列素材清单 + 缺口 + 问题。

## 用法

**第一次用（只做一次）：**

```
你好，我先发简历给你，帮我做用户诊断。
[附简历 PDF / Word / 图片 / 文字]
```

AI 会：读简历 → 提取事实层 → 只问简历里没有的 5 件事 → 产出 `00_用户诊断.md`。

**之后每家公司：**

```
快速蒸馏：<公司名>，<岗位名>
```

AI 会引用已有的 `00_用户诊断.md`，不再重复问。

产出八件套（按匹配度分闸，不是每家公司都做满）：

| # | 文件 | 何时做 |
|:--:|---|---|
| 00 | 用户诊断 | 第一次用做一次，之后复用 |
| 01 | 公司蒸馏（五层） | 全部 |
| 02 | 岗位蒸馏 | 全部 |
| 03 | **投递方案**（对外 A4） | S/A/B 必做，C 不做 |
| 04 | 证据附录 | 全部 |
| 05 | 投递动作包 | S/A 必做，B 选做 |
| 06 | 面试包（反向面试+谈薪+90天） | 受邀后 |
| 07 | 复盘与校准 | 投递/面试后 |

## 方法论概览

- **五层结构**：广度（行业视角）→ 宽度（信息）→ 深度（判断+洞察）→ 高度（视角）→ 决策（8 步推演 + 机会成本）。
- **第 -1 步**：先诊断人（弹药/短板/死门槛/主线/机会成本/3 个可证伪判断）。
- **5 条铁律**：时效红线 / 量纲验算 / 引用可核验 / 单一事实源 / 未取得三级降级。
- **评分模型**：匹配 40% + 薪资 20% + 健康 20% + 主线 20%，可复算，0 分不合并。
- **三轨分流**：筛选轨（快速过滤）/ 练习轨（按信息价值决定投入）/ offer 轨（做满）。
- **校准闭环**：决策日志 → 结果回填 → 每 5 家校准 → 更新判断规则。
