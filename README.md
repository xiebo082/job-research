# job-research · 快速蒸馏求职工作流

> 一套可复用的「研究公司 → 评估匹配 → 投递决策」工作流。核心不是「多收集资料」，而是「做决策」——该不该投、怎么差异化进、进去后验证什么。

## 一句话定位

把求职从「海投简历」变成「对目标公司做一次结构化尽调 + 一页投递方案」，用「方法」而不是「运气」提高约面率和入职后的判断力。

## 它解决什么问题

| 痛点 | 本工作流怎么解 |
|---|---|
| 海投没回复 | 一页差异化投递方案 + 六段式打招呼，让 HR 看到「你真的研究过」 |
| 面试被问倒 | 公司蒸馏五层，把公司从行业到决策摸透 |
| 入职踩坑 | 判断层 + 高度层，提前看「最可能错在哪」 |
| 长期不找工作也荒废 | 业务研究轨，不投也研究，练业务思考 |

## 目标用户

- 求职中的运营/市场/产品等岗位的人
- 想「看懂一家公司」的人（不限于求职）

## 安装

不同 AI 安装方式不同，核心是把 `SKILL.md` + `references/` + `examples/` 放进对应 skills 目录：

| AI | 方式 |
|---|---|
| Claude Code | 放 `~/.claude/skills/` 或 `/install` |
| Codex | 放 `.codex/skills/` |
| DeepSeek Harness | Skills Manager 导入 ZIP，或复制到 `~/.dsh/skills/` |
| 其他 AI | 把 SKILL.md 全文 + 标准 + JD 一起粘贴，当作提示词用 |

装完验证：说「快速蒸馏：某公司，某岗位」，看它是否先列素材清单 + 缺口 + 5 个问题。

## 用法

```
快速蒸馏：<公司名>，<岗位名>
```

产出六件套（按匹配度分闸，不是每家公司都做满）：

| # | 文件 | 何时做 |
|:--:|---|---|
| 01 | 公司蒸馏（五层） | 全部 |
| 02 | 岗位蒸馏 | 全部 |
| 03 | **投递方案**（对外 A4） | S/A/B 必做，C 不做 |
| 04 | 证据附录 | 全部 |
| 05 | 投递动作包 | S/A 必做，B 选做 |
| 06 | 面试包/入职推演 | 受邀后 |

## 方法论概览

- **五层结构**：广度（行业视角）→ 宽度（信息）→ 深度（判断+洞察）→ 高度（视角）→ 决策（7 步推演）。
- **5 条铁律**：时效红线 / 量纲验算 / 引用可核验 / 单一事实源 / 未取得三级降级。
- **评分模型**：匹配 40% + 薪资 20% + 健康 20% + 主线 20%，可复算，0 分不合并。
- **三轨分流**：筛选轨（快速过滤）/ 练习轨（按信息价值决定投入）/ offer 轨（做满）。
